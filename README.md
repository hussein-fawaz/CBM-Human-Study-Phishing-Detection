# Concept Explanation Study

Protocol page for a human study on concept bottleneck models (CBMs) for phishing detection:
can people catch an AI's mistakes when they see the concepts behind its decision?

**View it:** https://hussein-fawaz.github.io/CBM-Human-Study-Phishing-Detection/

The page is a single self-contained file (`index.html`). It explains what a concept bottleneck
model is, the three study arms (score only, black box with highlighted words, concepts), and walks
through every screen and question participants see, using real emails from the 2008 CEAS corpus.
Some of those emails are spam with adult wording.
